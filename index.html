Додати координати

Один рядок — одна або кілька точок. Десяткові (крапка чи кома), DMS, MGRS. Текст після координат стає назвою. Ctrl+Enter — додати.

Точки

0

Імпорт

Перетягніть файли сюди або натисніть, щоб вибрати (можна кілька) XLSX · XLS · ODS · CSV · TXT · GeoJSON · KML · JSON

Колонки розпізнаються автоматично: lat/lng (широта/довгота), MGRS, координати, дата, населений пункт, тип, примітка. Обробляються всі аркуші Excel.

Експорт

Резервну копію чи GeoJSON можна повернути через імпорт.

Малювання

Полігон: клікайте вершини, завершення — «Готово», Enter, подвійний клік або клік по першій вершині. Коло й прямокутник — двома кліками.

Дані

Точки в одному місці стають однією; різні дати, типи й назви записуються через кому. 0 — не об'єднувати.

Сесійний режим: у браузері нічого не зберігається. Після закриття вкладки все зникає, тож зберігайте роботу через «Файли → Резервна копія».
